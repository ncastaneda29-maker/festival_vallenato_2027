# Festival de la Leyenda Vallenata 2027 - Sistema de Votaciones

Aplicación web dinámica desarrollada en **Django** y **MySQL** utilizando el patrón arquitectónico **MVT** (Modelo - Vista - Plantilla) para la gestión y consulta de votaciones del Festival Vallenato 2027.

---

## Requisitos Previos

* **Python:** 3.12.x
* **Base de Datos:** MySQL 8.0 / MySQL Workbench
* **Navegador Web:** Google Chrome, Edge o Firefox

---
